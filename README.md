# 🧾 Invoice Expense Classifier API

A FastAPI-based REST API that classifies invoice text into expense categories using **TF-IDF + Logistic Regression** — no GPU or paid services required.

## Supported Categories

| Category | Example Invoice Text |
|---|---|
| Logistics | "Blue Dart courier charges for warehouse delivery" |
| Cloud/Software | "AWS monthly cloud hosting bill" |
| Office Supplies | "A4 paper reams purchase for office" |
| Travel | "Flight tickets Mumbai to Delhi team offsite" |
| Utilities | "Electricity bill for office premises April" |
| Inventory | "Raw material purchase steel sheets" |

## 🚀 Quick Start (Local — No Docker)

### Prerequisites
- Python 3.9 or higher
- pip

### Step 1 — Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/invoice-classifier.git
cd invoice-classifier
```

### Step 2 — Create and activate a virtual environment

```bash
# macOS / Linux
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

### Step 3 — Install dependencies

```bash
pip install -r requirements.txt
```

### Step 4 — Train the model

```bash
python scripts/train_model.py
```

You should see output like:
```
✅ Loaded 77 samples across 6 categories
Accuracy : 75.00%
✅ Model saved → app/model.pkl
```

### Step 5 — Start the API

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

The API is now running at **http://localhost:8000**

### Step 6 — View Interactive Docs

Open your browser and go to:
- **Swagger UI**: http://localhost:8000/docs
- **ReDoc**: http://localhost:8000/redoc

## 🐳 Docker Setup (Optional)

### Prerequisites

### Option A — Docker Compose (recommended)

```bash
docker-compose up --build
```

```bash
# Build the image
docker build -t invoice-classifier .

# Run the container
docker run -p 8000:8000 invoice-classifier
```

## 📡 API Usage Examples

### Single Prediction

```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"text": "Blue Dart courier charges for warehouse delivery"}'
```

**Response:**
```json
{
  "category": "Logistics",
  "confidence": 0.8921,

    { "category": "Utilities",       "confidence": 0.0112 },
```

## ⚙️ How It Works

1. **Preprocessing** — Input text is lowercased and special characters removed
2. **TF-IDF Vectorization** — Converts text to a numeric matrix using unigrams + bigrams (`ngram_range=(1,2)`)
3. **Logistic Regression** — Multinomial classifier predicts the category
4. **Confidence Score** — Probability from `predict_proba` is returned alongside the category

To improve accuracy, add more rows to `data/training_data.csv` and re-run `python scripts/train_model.py`.
